# webcam-stream

Трансляция веб-камеры в интернет под логином и паролем. Без аккаунтов и сторонних
сервисов: локальный сервер отдаёт картинку, Cloudflare Tunnel выдаёт публичную
ссылку `https://`.

```
камера  ->  локальный MJPEG-сервер (Basic Auth)  ->  Cloudflare Tunnel  ->  https-ссылка
```

- **Под паролем.** Без логина и пароля не видно ничего, соединение идёт по HTTPS.
- **Portable.** Собирается в один `WebcamStream.exe`, установки не требует.
- **Задержка меньше секунды** — в отличие от трансляций через YouTube.
- **Нигде не нужен аккаунт.** Быстрые туннели Cloudflare работают без регистрации.

## Быстрый старт

**Вариант 1: скачать exe.** Взять `WebcamStream.exe` из
[релизов](../../releases), запустить, выбрать камеру, задать пароль, нажать Start.

**Вариант 2: запустить из исходников.**

```bash
pip install -r requirements.txt
python webcam_gui.py            # окно с настройками
python webcam_stream.py         # командная строка, без окна
```

**Вариант 3: собрать exe самому.** Запустить `build_exe.bat` на Windows. Он поставит
PyInstaller, соберёт проект во временной папке с коротким путём (ограничение длины
пути в Windows — вполне реальная проблема) и положит `WebcamStream.exe` рядом с
исходниками.

При первом запуске программа скачивает рядом с собой `cloudflared.exe` (~50 МБ).
Это единственная внешняя зависимость, и она остаётся локальной.

## Окно программы

- **Find cameras** перебирает все номера камер и способы захвата и показывает те,
  что реально отдают кадры.
- Логин, пароль, генератор пароля и галочка «запоминать пароль».
- Публичная ссылка с кнопками **Copy** и **Open**, рядом — адрес в домашней сети.
- Автозапуск: трансляция стартует сразу при открытии программы.

Настройки лежат в `settings.json` рядом с программой. Пароль шифруется через
Windows DPAPI и привязан к учётной записи — файл, скопированный на другой
компьютер, пароль не выдаст.

## Командная строка

```bash
python webcam_stream.py --user roman --password секрет
python webcam_stream.py --list-cameras     # диагностика проблем с камерой
python webcam_stream.py --no-tunnel        # только домашняя сеть
```

| Ключ | Что делает | По умолчанию |
| --- | --- | --- |
| `--user` | логин | `admin` |
| `--password` | пароль | случайный, печатается при запуске |
| `--no-tunnel` | только локальная сеть | выключено |
| `--camera N` | номер камеры | `0` |
| `--backend` | `msmf`, `dshow`, `any` | перебираются все |
| `--width` / `--height` | разрешение | `1280x720` |
| `--fps` | кадров в секунду | `15` |
| `--quality` | качество JPEG, 1–100 | `70` |
| `--port` | порт локального сервера | `8080` |
| `--list-cameras` | показать рабочие камеры и выйти | — |

Логин и пароль можно передать через переменные окружения `CAM_USER` и
`CAM_PASSWORD` — тогда они не останутся в истории команд.

## Адреса

| Путь | Что отдаёт |
| --- | --- |
| `/` | страница просмотра с автопереподключением |
| `/stream.mjpg` | сам MJPEG-поток |
| `/snapshot.jpg` | один текущий кадр, удобно для скриптов и виджетов |

## Про безопасность

- Basic Auth надёжен ровно настолько, насколько надёжен транспорт. Через туннель
  всё идёт по HTTPS, пароль шифруется. С `--no-tunnel` соединение обычное HTTP —
  для домашней сети нормально, наружу так отдавать не стоит.
- Неверные попытки входа притормаживаются на секунду, чтобы усложнить перебор.
- Ссылка быстрого туннеля случайная и меняется при каждом запуске. Постоянный
  адрес требует аккаунта Cloudflare, именованного туннеля и своего домена.
- Страница отдаёт `noindex` и `X-Frame-Options: DENY` — в поиск не попадёт и во
  фрейм её не вставят.

## Если что-то не работает

Начинать отсюда:

```bash
python webcam_stream.py --list-cameras
```

| Симптом | Причина и что делать |
| --- | --- |
| `camera opened but delivers no frames` | чаще всего Python из Microsoft Store: он в песочнице и до камеры не дотягивается. Поставьте Python с python.org. Ещё проверьте Параметры → Конфиденциальность → Камера |
| `could not get a picture` | камеру занял другой софт — закройте Zoom, Skype, Teams; или попробуйте `--camera 1` |
| Нет ссылки `trycloudflare` | туннель не поднялся; проверьте интернет и антивирус. Локальный адрес при этом работает |
| Картинка замирает | страница переподключается сама через 3 секунды; если нет — кнопка Refresh |
| `port is not available` | порт занят другой программой, запустите с `--port 8081` |
| Сборка падает с `WinError 206` | слишком длинный путь; `build_exe.bat` уже собирает в `%TEMP%`, либо перенесите проект в `C:\webcam-stream` |

## Что нужно

- Windows 10/11, macOS или Linux
- Python 3.8+ с OpenCV (`pip install -r requirements.txt`)
- Веб-камера

Окно и шифрование через DPAPI рассчитаны прежде всего на Windows. На macOS и Linux
всё работает, но пароль сохраняется открытым текстом — программа об этом
предупреждает.

## Тесты

Ни камера, ни графическая подсистема не нужны: вместо камеры подставляется
сгенерированный видеофайл, вместо tkinter — заглушка.

```bash
python tests/test_server.py    # захват, авторизация, MJPEG, восстановление
python tests/test_gui.py       # хранилище настроек, логика окна, запуск целиком
```

## Нагрузка на канал

Примерно 1,5–3 Мбит/с на каждого зрителя при 720p и 15 кадрах в секунду. Если
интернет слабый или зрителей много, снизьте: `--quality 50 --fps 10` или
`--width 854 --height 480`.

Звука нет: MJPEG передаёт только картинку.
