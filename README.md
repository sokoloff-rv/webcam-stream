# webcam-stream

Приложение позволяет организовать трансляцию изображения с веб-камеры в интернет без 
аккаунтов и сторонних сервисов. Локальный сервер отдаёт картинку, Cloudflare Tunnel 
выдаёт публичную https-ссылку.

*   **Приватно:** Доступ к трансляции только по логину и паролю.
*   **Быстро:** Задержка меньше секунды (в отличие от стримов на YouTube).
*   **Без регистрации:** Quick Tunnels от Cloudflare не требует авторизации.
*   **Portable:** Не требует установки, можно собрать в один `.exe`.

## Запуск

**Вариант 1: Самый простой (Windows)**
Скачайте `WebcamStream.exe` из [релизов](../../releases), запустите, придумайте пароль и нажмите Start. 
*При первом запуске программа скачает `cloudflared.exe` (~50 МБ) в ту же папку. Больше в систему ничего не ставится.*

**Вариант 2: Для гиков (из исходников)**
```bash
pip install -r requirements.txt
python webcam_gui.py     # Запустить интерфейс
python webcam_stream.py  # Запустить только в консоли
```

**Вариант 3: Собрать `.exe` самому**
Запустите `build_exe.bat` (Windows). Он сам установит PyInstaller и соберет бинарник. Сборка идет во временной папке `%TEMP%`, чтобы обойти виндовые проблемы с длинными путями, а готовый экзешник появится рядом с исходниками.

## Что внутри GUI

*   **Умный поиск камер:** Кнопка `Find cameras` честно проверяет, какие камеры реально отдают картинку, а не просто висят в диспетчере устройств.
*   **Безопасное хранение:** Пароль шифруется средствами Windows (DPAPI) и привязан к вашей учетной записи. Если кто-то скопирует ваш `settings.json` на другой компьютер, пароль он не узнает.
*   **Удобство:** Показывает сразу две ссылки (публичную и для локальной сети), умеет автостартовать при запуске.

## Использование из консоли

```bash
python webcam_stream.py --user admin --password secret
```
*Совет: логин и пароль можно передать через переменные окружения `CAM_USER` и `CAM_PASSWORD`, чтобы они не светились в истории команд bash/powershell.*

**Полезные флаги:**
*   `--list-cameras` — диагностика: покажет, какие камеры сейчас живы.
*   `--no-tunnel` — не пускать в интернет, стримить только в локалку.
*   `--camera N` — выбрать конкретную камеру (по умолчанию 0).
*   `--width`, `--height`, `--fps`, `--quality` — настройки картинки (по умолчанию 1280x720, 15 fps, JPEG quality 70).
*   `--port` — сменить порт локального сервера (по умолчанию 8080).

## API / Эндпоинты

*   `/` — веб-плеер (страница сама переподключается при обрывах).
*   `/stream.mjpg` — сырой MJPEG-поток.
*   `/snapshot.jpg` — отдает один свежий кадр (идеально для скриптов, ботов и дашбордов).

## Пару слов о безопасности

*   Basic Auth поверх HTTPS через туннель — это надежно. Главное, не светите логин/пароль с флагом `--no-tunnel` во внешней сети (это будет голый HTTP).
*   Защита от брутфорса: при неверном пароле сервер искусственно тормозит ответ на 1 секунду.
*   Ссылка Cloudflare меняется при каждом перезапуске. Постоянный адрес можно сделать, но для этого понадобится аккаунт Cloudflare и свой домен.
*   Сама страница закрыта от встраивания в чужие фреймы (`X-Frame-Options: DENY`) и от поисковиков (`noindex`).

## Если что-то не работает

Начните с команды диагностики: `python webcam_stream.py --list-cameras`

| Симптом | В чем проблема и что делать |
| --- | --- |
| `camera opened but delivers no frames` | Классика. Скорее всего, у вас Python из Microsoft Store — он сидит в песочнице и не видит камеру. Поставьте нормальный с python.org. Также проверьте в Windows: *Параметры → Конфиденциальность → Камера*. |
| `could not get a picture` | Камера занята. Закройте Zoom, Skype, OBS и т.д. Или попробуйте запустить с `--camera 1`. |
| Нет ссылки `trycloudflare` | Туннель не поднялся. Проверьте интернет, антивирус или фаервол. Локальный адрес при этом должен работать. |
| Картинка замирает | Страница должна переподключаться сама через 3 секунды. Если нет — жмите Refresh. |
| `port is not available` | Порт 8080 занят другой программой. Запустите с флагом `--port 8081`. |
| Сборка падает с `WinError 206` | Слишком длинный путь. Перенесите папку с проектом поближе к корню (например, в `C:\webcam-stream`). |

## Системные требования

*   Windows 10/11, macOS или Linux. *(Учтите: GUI и шифрование DPAPI заточены под Windows. На macOS и Linux всё работает, но пароль сохраняется в конфиге открытым текстом).*
*   Python 3.8+ с OpenCV (`pip install -r requirements.txt`).
*   Любая вебкамера.

## Нагрузка на сеть

MJPEG довольно прожорлив. 720p при 15 кадрах в секунду отъест **1.5–3 Мбит/с на каждого зрителя**. Если канал узкий, режьте качество:
`--quality 50 --fps 10` или `--width 854 --height 480`.

*Звука нет, MJPEG передает только картинку.*
